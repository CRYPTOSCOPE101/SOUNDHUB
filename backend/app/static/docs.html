SoundHub API

Version control and collaboration for music production. Full-stack API covering project management, review sessions with A/B comparison, delivery packages with audit trails, payments, and public portfolios.

v0.1.0 REST + JSON OpenAPI 3.1 JWT Bearer Auth

Authentication

Every authenticated request requires a Bearer token in the Authorization header. Tokens are obtained by logging in or registering.

Shell
# 1. Log in
curl -X POST https://soundhub-backend.onrender.com/api/auth/login \
     -H "Content-Type: application/json" \
     -d '{"username": "demo", "password": "demo123"}'

# 2. Use the token
curl https://soundhub-backend.onrender.com/api/projects \
     -H "Authorization: Bearer eyJhbGciOi..."
ℹ️
Tokens expire after 7 days (configurable via SOUNDHUB_TOKEN_EXPIRE_MINUTES).

Base URL

Production
https://soundhub-backend.onrender.com/api

Error Handling

Error Response
{ "detail": "Invalid username or password" }

204No Content (DELETE)

401Unauthorized — missing or invalid token
403Forbidden — not the session owner
404Not Found
422Validation Error — field type mismatch
500Internal Server Error

Login & Registration

POST/api/auth/login

Log in with username + password. Returns JWT access token + user profile.

POST/api/auth/register

Create a new account. Same payload and response shape as login.

Wallet Login (EVM)

POST/api/auth/wallet/nonce

Request a signing nonce for a wallet address. Returns nonce + message to sign.

FieldTypeDescription
addressstringEthereum address (0x…)
POST/api/auth/wallet/login

Verify the signed message and return a JWT. Links on-chain identity to your SoundHub account.

FieldTypeDescription
addressstringWallet address
messagestringMessage that was signed
signaturestringSigned message from MetaMask

PATCH/api/auth/me

Update profile fields.

FieldTypeDescription

specialtystringmix_master, recording, mastering, etc.
locationstringCity / country

Projects

Projects are version-controlled containers — like Git repos for DAW files (.als, .rpp, .flp, .cpr).

GET/api/projects

List all projects owned by the authenticated user.

POST/api/projects

Create a new project.

FieldTypeDescription
namestringProject name (required)
descriptionstringShort description
GET/api/projects/{id}

Get project details, last commit, and metadata.

PATCH/api/projects/{id}

Update project name or description.

DEL/api/projects/{id}

Delete a project and all its branches/commits.

Branches

GET/api/projects/{id}/branches

List all branches (GitHub-style).

POST/api/projects/{id}/branches

Create a new branch from an existing one.

FieldTypeDescription
namestringBranch name
from_branchstringSource branch (default: main)
DEL/api/projects/{id}/branches/{name}

Delete a branch (except main).

Commits & Push

GET/api/projects/{id}/commits

List commits. Optional: ?branch=main.

GET/api/projects/{id}/commits/{commitId}

Full commit details with file tree and DAW metadata (tracks, plugins, instruments).

POST/api/projects/{id}/commits

Upload a new commit with files (multipart/form-data).

FieldTypeDescription
messagestringCommit message (required)
branchstringTarget branch (default: main)
filesfile[].als, .cpr, .rpp, .flp, etc.
POST/api/projects/{id}/push

Atomic push — used by snd push. Uploads DAW files + optional master audio + stems as one transaction. Returns a stable JSON contract with project_id, version_id, review_url, and dedup stats.

FieldTypeDescription
filesfile[]DAW project files (required)
messagestringCommit message
manifeststringJSON manifest from snd push
branchstringTarget branch
audiofileMaster audio — opens a review version
stemsfile[]Stem renders for A/B

File Tree & Diff

GET/api/projects/{id}/tree

Recursive file tree. Query: ?branch=main or ?commit_id=3.

GET/api/projects/{id}/diff

File diff between two commits/branches. Query: ?path=track.als&from_branch=main&to_branch=feat/v2.

GET/api/projects/{id}/files/{path}

Download a file at its latest state. Add ?download=1 for Content-Disposition.

GET/api/projects/{id}/files/{path}/info

File metadata: size, sha256, content type.

POST/api/projects/{id}/release

Bind a blockchain release (NFT contract) to a project.

FieldTypeDescription

DEL/api/projects/{id}/release

Remove the release binding from a project.

Review Sessions

Frame.io-style collaboration workflow: upload versions, collect timestamped comments, track approvals, manage revisions.

POST/api/sessions

Create a review session (optionally linked to a project).

FieldTypeDescription
namestringSession name (required)
project_idintLink to an existing project
GET/api/sessions/{id}

Full session details: versions, brief, share settings, team, ledger summary.

GET/api/sessions

List all sessions for the authenticated user.

DEL/api/sessions/{id}

Delete a session and all its versions/comments.

Versions

Upload audio files (WAV, MP3, FLAC, etc.) and track them through the review lifecycle. The backend generates waveforms and loudness analysis automatically.

POST/api/sessions/{id}/versions

Upload a new audio version (multipart/form-data, max 2 GiB).

FieldTypeDescription
fileaudioAudio file (required)
messagestringVersion notes
POST/api/sessions/{id}/versions/{vId}/status

Set version status: in_review, approved, changes_requested, replaced.

GET/api/sessions/{id}/versions/{vId}/audio

Stream the version's audio file.

GET/api/sessions/{id}/versions/{vId}/diff

Compare two consecutive versions (metadata diff).

PATCH/api/sessions/{id}/versions/{vId}/comments/{cId}

Resolve or unresolve a comment: ?resolved=true.

Ledger & Audit Trail

Every significant event (version upload, comment, approval, payment, feedback) is recorded with SHA-256 proof.

GET/api/sessions/{id}/ledger

Full event log with hashes and payloads.

GET/api/sessions/{id}/ledger/verify

Verify the chain of hashes — returns integrity status.

Audio Analysis

GET/api/versions/{versionId}/audio-analysis

Loudness analysis: LUFS, true peak, dynamic range, waveform JSON for rendering.

Version Comparison (A/B)

Compare any two versions with automatic LUFS level matching for fair A/B testing.

POST/api/comparisons

Create an A/B comparison.

FieldTypeDescription

end_msintEnd point (optional)

stem_logical_namestringFor stem mode: which stem to isolate
GET/api/comparisons/{comparisonId}

Get comparison results: waveform overlays, loudness stats.

POST/api/sessions/public/{token}/compare

Public A/B comparison (same payload).

Release Packages

Final delivery bundles: approved version + deliverables (master, stems, artwork, metadata) + verified release manifest with SHA-256 audit trail.

POST/api/release-packages

Create a release package from an approved version.

GET/api/release-packages

List packages. Query: ?session_id=….

Package Templates

GET/api/release-packages/templates

Available delivery templates with required deliverable types.

Deliverables

POST/api/release-packages/{id}/deliverables/from-version

Attach a version's audio as a deliverable.

FieldTypeDescription
typestringmaster, instrumental, vocals, stems_zip, artwork, etc.
from_version_idintVersion to pull audio from
POST/api/release-packages/{id}/deliverables/upload

Upload a deliverable file directly (artwork, metadata CSV, etc.).

Lock & Manifest

POST/api/release-packages/{id}/lock

Lock the package — generates an immutable release manifest with SHA-256 hash for audit trail.

GET/api/release-packages/{id}/manifest

Get the release manifest JSON + hash.

Preflight

POST/api/release-packages/{id}/preflight

PATCH/api/release-packages/{id}/handoff

Search

GET/api/search?q={query}

Full-text search across engineers (with public portfolios) and public sessions. Returns grouped results with session counts.

Public Portfolio

Every engineer with public sessions gets an auto-generated portfolio page.

GET/api/portfolio/{username}

Public portfolio: bio, specialty, approved versions, and links to session reviews.

GET/api/portfolio/{username}/preview/{versionId}

Stream a portfolio preview of a version's audio.

Reminders & Notifications

Automated email reminders for pending reviews, overdue feedback, and invoice due dates. Requires SMTP configuration (SMTP_HOST env var).

POST/api/reminders/evaluate

Trigger the evaluation engine — scans all sessions and sends due notifications. Returns counts: {evaluated, created, sent, failed}.

GET/api/sessions/{id}/reminders

List queued and sent reminders for a session.

PATCH/api/sessions/{id}/reminders

Update reminder settings: enable/disable, set recipients, configure intervals.

Opt-Out

POST/api/sessions/public/{token}/reminders/opt-out

Client opts out of all future reminders for this session. Returns {opted_out, dismissed}.
