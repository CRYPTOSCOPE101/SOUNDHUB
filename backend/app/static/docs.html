SoundHub API

Professional version control and collaboration for music production. Full-stack API with review workflows, A/B comparison, delivery packages, analytics, webhooks, and public portfolios.

v0.1.0 REST + JSON OpenAPI 3.1 JWT Bearer Auth

Authentication

Every authenticated request requires a Bearer token in the Authorization header.

Shell
# 1. Log in
curl -X POST https://soundhub-backend.onrender.com/api/auth/login \
     -H "Content-Type: application/json" \
     -d '{"username": "demo", "password": "demo123"}'

# 2. Use the token
curl https://soundhub-backend.onrender.com/api/projects \
     -H "Authorization: Bearer eyJhbGciOi..."

Base URL

Production
https://soundhub-backend.onrender.com/api

Error Handling

StatusMeaning
200Success
201Created
204No Content (DELETE)
400Bad Request — invalid payload
401Unauthorized — missing or invalid token
404Not Found
422Validation Error — field type mismatch
500Internal Server Error

Login & Registration

POST/api/auth/login

Log in with username + password. Returns JWT access token + user profile.

POST/api/auth/register

Create a new account. Same payload and response shape as login.

Wallet Login (EVM)

POST/api/auth/wallet/nonce

Request a signing nonce for a wallet address. Returns nonce + message.

POST/api/auth/wallet/login

Verify the signed message and return a JWT. Links on-chain identity to your account.

Profile

GET/api/auth/me

Current user profile.

PATCH/api/auth/me

Update profile: bio, specialty, location.

Projects

Version-controlled containers for DAW files (.als, .rpp, .flp, .cpr).

POST/api/projects

PATCH/api/projects/{id}

DEL/api/projects/{id}

Delete a project.

GET/api/projects/{id}/branches

List branches.

Create branch from existing. Fields: name, from_branch.

DEL/api/projects/{id}/branches/{name}

Delete a branch.

Commits & Push

GET/api/projects/{id}/commits

List commits. Query: ?branch=main.

GET/api/projects/{id}/commits/{commitId}

Commit details with DAW metadata.

POST/api/projects/{id}/commits

Upload files (multipart). Fields: message, branch, files.

POST/api/projects/{id}/push

Atomic push — used by snd push. Returns {project_id, version_id, review_url, uploaded, deduplicated}.

File Tree & Diff

GET/api/projects/{id}/tree

Recursive file tree. Query: ?branch=main or ?commit_id=3.

GET/api/projects/{id}/diff

Diff between commits/branches. Query: ?path=&from_branch=&to_branch=.

GET/api/projects/{id}/files/{path}

Download a file. Add ?download=1.

Session Templates NEW

Reusable session configurations — create once, apply to many sessions.

GET/api/templates

List your templates.

GET/api/templates/public

Browse public community templates.

POST/api/templates

Create a template. Fields: name, service_type, genre, included_rounds, extra_round_price_cents, deposit_due_cents, required_deliverables, brief_template, is_public.

GET/api/templates/{id}

Get template details.

DEL/api/templates/{id}

Delete a template.

Example — Create a mixing template
curl -X POST https://soundhub-backend.onrender.com/api/templates \
     -H "Authorization: Bearer $TOKEN" \
     -H "Content-Type: application/json" \
     -d '{
  "name": "Standard Mix",
  "service_type": "mix_master",
  "genre": "electronic",
  "included_rounds": 3,
  "extra_round_price_cents": 5000,
  "required_deliverables": "master,instrumental,stems_zip",
  "brief_template": "Genre: electronic. Reference: [link]. Keep the vocal balance.",
  "is_public": true
}'

Webhook Management NEW

Notify external services (Slack, Discord, CI/CD, etc.) when events happen.

GET/api/webhooks

List your webhooks.

POST/api/webhooks

Create webhook. Fields: url, events (comma-separated or *), secret (HMAC signing).

PATCH/api/webhooks/{id}

Update webhook. Fields: url, events, is_active.

DEL/api/webhooks/{id}

Delete webhook.

POST/api/webhooks/{id}/test

Send test event to verify endpoint.

GET/api/webhooks/{id}/deliveries

Delivery history with status codes and timing. Query: ?limit=20.

Example — Create a Slack webhook
curl -X POST https://soundhub-backend.onrender.com/api/webhooks \
     -H "Authorization: Bearer $TOKEN" \
     -H "Content-Type: application/json" \
     -d '{
  "url": "https://hooks.slack.com/services/T.../B.../xxx",
  "events": "session.created,comment.added,approval.submitted",
  "secret": "your-hmac-secret"
}'
🔐
Webhook signatures: If a secret is set, each delivery includes an X-Signature header with HMAC-SHA256 of the JSON payload. Verify it to ensure the webhook came from SoundHub.
