🔐 Authentication Flow

Two auth methods: JWT (password) + Web3 Wallet (signature)

🔑 JWT Authentication

1
User registers with username + password
2
Password hashed with PBKDF2-SHA256 (260k iterations)
3
JWT token issued with user_id + username + exp
4
Token expires in 7 days (configurable)
5
Protected routes check Authorization: Bearer <token>
Password Hashing
salt = os.urandom(16)
digest = pbkdf2_hmac("sha256", password, salt, 260000)
stored = "pbkdf2$260000${salt_hex}${digest_hex}"

🦊 Web3 Wallet Authentication

1
Client sends wallet_address to /api/auth/wallet/nonce
2
Server generates nonce + message to sign (5min TTL)
3
User signs message with MetaMask (personal_sign)
4
Client sends address + message + signature
5
Server recovers signer via eth_account.Account.recover_message
6
If recovered == address → JWT issued. Account auto-created if new.
Signature Verification
recovered = Account.recover_message(
encode_defunct(text=message),
signature=signature
)
assert recovered.lower() == address.lower()
