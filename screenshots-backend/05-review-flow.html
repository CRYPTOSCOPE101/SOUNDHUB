🎧 Review Session Flow

The core review loop — from upload to approval

1
Create Session
Engineer creates a review workspace with a name and optional project link. A unique share token is generated.
API: POST /api/sessions
2
Configure Brief
Set service type (mix/master), genre, deadline, reference links, and "do not change" notes. Fixed before first bounce.
API: PATCH /api/sessions/{id}/brief
3
Upload Version
Engineer uploads WAV/MP3. Stored as content-addressed blob (SHA-256). Waveform peaks generated immediately. Loudness analysis runs in background.
API: POST /api/sessions/{id}/versions
4
Share Link
Engineer shares the review link. Optional: password, expiry, allowlist, permission level (view/comment/download).
API: PATCH /api/sessions/{id}/share
5
Guest Feedback
Reviewers leave timestamped comments (text or voice notes). No account needed. Comments are "draft" until feedback owner consolidates.
API: POST /api/sessions/public/{token}/versions/{v}/comments
6
Smart Diff
Compare versions at project level: BPM, tracks, plugins, samples. Never "binary file changed".
API: GET /api/sessions/public/{token}/versions/{v}/diff
7
Approve Version
Reviewer approves (mix/master/release scope) or requests changes. Role-based gates for enforced presets.
API: POST /api/sessions/public/{token}/versions/{v}/approvals
8
Upload New Version
Engineer uploads fixes. Unresolved comments are carried forward. Round number increments.
API: POST /api/sessions/{id}/versions
9
Lock Package
Create immutable release package. SHA-256 manifest computed. Files frozen — approved master can never be swapped.
API: POST /api/release-packages → PATCH /api/release-packages/{id}/lock
10
Deliver
Public delivery link with token. Client downloads final files. Invoice status tracked. Decision ledger verified.
API: GET /api/release-packages/public/{token}
