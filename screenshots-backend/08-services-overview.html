⚙️ Services Overview

15+ service modules — the business logic layer

💾 Storage

Content-addressed blob storage. Files stored by SHA-256 hash. Identical files stored once — dedup is automatic.
put_blob() read_blob() blob_exists()

📊 Waveform

Peak generation for audio visualization. Extracts from WAV PCM data or generates synthetic fallback.
generate() → peaks + duration

🔊 Analysis

Loudness analysis — integrated LUFS, true peak, sample rate, channels. Runs in background after upload.
analyse_version()

🎵 Watermark

Audible watermarking for unapproved previews. Leaked preview is traceable and never "the final file".
watermarked_blob()

🔗 Ledger

Tamper-evident decision log. SHA-256 hash chain: rewriting an old event invalidates every subsequent hash.
append() verify_history()

📁 Versioning

File snapshots and tree navigation. Track file history across commits. Git-like for DAW projects.
tree_files() file_in_commit() file_history()

👥 Roles

Team roles and approval gate enforcement. 4 presets: solo_client, artist_team, label_workflow, post_production.
member_role() role_can_approve()

📧 Reminders

Email reminders with SMTP transport. Deduplication at DB level. Client opt-out for non-critical.
evaluate() send_pending() _deliver()

🔔 Webhooks

HTTP webhook dispatching with HMAC signing. Retry on failure. Full delivery audit trail.
dispatch() → POST to URL

💳 Stripe Pay

Stripe Checkout integration. Session-level charges: deposits, extra rounds, delivery invoices.
create_checkout_session()

⛓ USDC Pay

USDC on-chain payments on Base network. Native USDC (0x833589...). 6 decimals.
usdc_to_raw() raw_to_usdc()

⭐ Reputation

Engineer reputation scoring from real session data. Badges: Gold (400+), Silver (250+), Bronze (100+).
compute_reputation() badge_for_score()

📋 Templates

Reusable session templates. Mix, mastering, production configs with pricing and deliverables.
list_templates() create_template()

🏷 Tags

Tag management for sessions. Many-to-many links. Filter by genre, mood, status, priority.
link_tag() session_tags()

📂 Groups

Folder organization for sessions. Hierarchical with parent-child. Sort order support.
link_session() group_sessions()

🎹 DAW Parsers

Parse Ableton (.als), REAPER (.rpp), Cubase (.cpr), FL Studio (.flp). Extract BPM, tracks, plugins.
detect_format() get_daw_info()

🔍 Diff Engine

Smart diff for DAW projects. Compares BPM, tracks, plugins, samples. Never "binary file changed".
summary_diff() unified_diff()

📊 Analytics

Session statistics: total sessions, versions, comments, approvals. Sessions by status.
get_user_analytics()
